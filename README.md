# Paradox-Engine

An interactive collection of mathematical and logical paradoxes presented as a small digital museum. The Next.js and React frontend organises exhibits including the Monty Hall problem and Zeno's paradoxes.

## Run locally

Install dependencies and start the Next.js development server:

    npm install
    npm run dev

Build the production version with:

    npm run build

The package also provides `npm start` to serve a completed production build.

## Explore the code

Page routes are under `app/`, reusable interface elements under `components/`, and exhibit material under `content/`. When adding an exhibit, explain its assumptions and reasoning clearly.
